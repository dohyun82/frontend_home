TEST 01 · 식권대장 OneLink 딥링크

AppsFlyer OneLink(vendys.onelink.me/szhg) → 식권대장 앱 OAuth 화면 진입

01 기대 동작

앱 설치됨 식권대장 앱 실행 → screen/main/oauth 진입
앱 미설치 스토어(Play 스토어 / App Store)로 이동
테스트 브라우저 삼성 인터넷 (Samsung Internet)
딥링크는 사용자 탭(제스처)으로 실행해야 합니다. 자동 리다이렉트는 브라우저가 차단할 수 있으므로 이 페이지는 자동 이동을 하지 않습니다.

02 딥링크 실행

아래 버튼을 눌러 실행합니다. 로그를 계속 보려면 새 탭 방식을 쓰세요.

식권대장 앱 열기 (같은 탭)
실행 대상: 원본 URL — 아래 03에서 파라미터를 수정하면 자동으로 재생성 URL로 전환됩니다.
